# StudyFlow v2.1

Фокус-сесії для навчання: завдання, таймери сесії та завдання, пауза/продовження, підсумок, налаштування нагадувань, теми.

## Що нового у v2.1
- Налаштування "Коли нагадувати" тепер працює:
  - "Після кожного завдання" - сповіщення після кожного виконаного завдання;
  - "Наприкінці сесії" - під час сесії сповіщень немає, після завершення - одне підсумкове з переліком виконаних.
- Новий маршрут `GET /api/settings`.
- Нагадування "Залишилося 5 хвилин" працює в обох режимах.
- Додано статичну версію для GitHub Pages у папці `docs/` (зберігання - localStorage).

## Запуск (Flask)
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Відкрийте http://127.0.0.1:5000

Дані зберігаються у `study_data.json` (створюється автоматично).

## Статична версія (GitHub Pages)
Папка `docs/` - повністю статичний варіант застосунку (без сервера, дані у localStorage).
Локальна перевірка:
```bash
python -m http.server 8017 --directory docs
```

## Публікація на GitHub Pages
1. Створити репозиторій `StudyFlow_v2.1-site`.
2. Завантажити вміст проєкту у гілку `main`.
3. Settings -> Pages -> Source: Deploy from a branch -> Branch: `main`, folder: `/docs` -> Save.
4. Сайт: `https://<username>.github.io/StudyFlow_v2.1-site/`

## Обмеження прототипу
- Активна сесія не зберігається після перезавантаження сторінки.
- "Продовжити (+5 хв)" не перевіряє залишок часу сесії.
- Системні Notification доступні лише після дозволу браузера (дозвіл запитується вручну у налаштуваннях браузера).
